# 每日英语 · 鸿蒙个人版

面向 HarmonyOS 6 / 6.1 的原生 ArkTS 工程。主页面为学习日历，所有词单和设置保存在手机本地，不需要自行部署后端。

**当前交付是源码工程，尚不是可安装成品。** 开发电脑尚未安装 DevEco Studio，用户暂缓华为账号与实名认证，因此本次未完成 Huawei SDK 编译、签名、模拟器或真机验证，没有生成 HAP。不能将 ZIP 重命名为 HAP 安装。用户提供的目标系统为 6.1.0.135；须在实际设备上完成下述验收后，才能确认可用。

## 已实现

- 真实日期日历：周一开头、跨月/跨年、闰年、回到今天、点击日期查看词单。
- 领域可多选，每个领域每天各 1–20 个词。例如职场＋计算机，每领域 5 词，则每天共 10 词；至少选择一个领域，设置页实时显示总量。
- 1000 个不重复内置词条，五个领域各 200 词。保留原 150 词的双语例句；新增 850 词的中文释义、音标来自 ECDICT，未编造缺失例句。保留仓库原有 9 天的 45 个单词和 9 个短语记录。
- 音频滚动缓存：过去 7 天＋今天＋未来 20 天，共 28 个日期，重复单词只下载一次。过期音频清理，历史文字不删除；例句、短语和未缓存单词使用系统 TTS。支持 0.75×、1×、1.25×。
- 优先安排未出现的词；每个领域词库耗尽后按最早出现的顺序复习，并显示“复习”。跨领域同日去重；自定义领域可用不重复词不足时明确提示，不少发或虚构词条。
- 历史搜索、逐词学习标记。未记录的过去日期保持空白，不虚构推送。
- 设置保存；数量、领域修改仅重建未来词单，今天及历史保持原样。首次默认日常交流、每天 5 词、09:00；提醒和手动在线词典关闭，音频自动更新开启。旧单领域设置和备份兼容；旧“全部领域”按五个内置领域分别计数。
- 系统日历提醒：每天一条，包含当天的 N 个词及释义；每次打开应用补足未来 30 天。再次同步不会重复创建，修改时间会更新，关闭会清理未来提醒。
- 手机直接访问公共词典：Free Dictionary API 查词，Datamuse 按英文领域查候选词；确认后加入本地词库。在线结果保留英文原释义，不伪造中文翻译。
- 本地安全写入、上一版备份、损坏恢复；用户可导出 JSON 或合并导入旧备份。合并不会覆盖当前已有词单、设置，也不会把其他设备的日历 ID 带入。

## 无后端提醒的边界

鸿蒙手机上的后台代理提醒受权益管控，因此个人版采用官方建议的 Calendar Kit 路径，用户开启后申请日历读写权限，只操作“每日英语”专属日历的应用事件。

提醒由**系统日历**通知，不是应用服务器推送；点击系统通知进入日历，可看到当天词单，发音与学习标记在本 App 中操作。通知是否显示还取决于系统日历通知设置、勿扰模式等，代码不会把“已登记”当作“已送达”。

30 天词单会提前本地安排，退出应用不需要联网就能提醒。超过计划期限一直不打开应用，不会无限产生新词单；重新打开可补足计划。不能承诺进程被杀后每日定时联网取词。改变时区后应打开 App 重新同步。卸载前先关闭提醒并完成同步，避免系统日历保留未来日程。

## 音频自动更新

即使关闭提醒，也准备今天至未来第 20 天的词单。应用前台启动、恢复联网以及前台周期检查时自动补齐缺少的发音。后台登记约 6 小时周期的 WorkScheduler 联网任务，实际是否执行、何时执行由系统决定；每轮限定工作预算，未完成的下次继续，不承诺后台准点更新。强行停止应用或系统限制后台时，重新打开会补齐和清理。

发音通过 Free Dictionary API 提供的 HTTPS MP3 地址下载，不需要自建后端或账号。音频按词单日期保留，不按下载日期计算。每个文件最多 512 KiB，音频总量上限 64 MiB；达到上限时显示提示，未缓存词使用系统语音。词典无录音、网络不可达时按小时重试，也可以手动重试。下载使用 Wi-Fi 或移动网络，可关闭“联网自动更新音频”。

缓存位于应用 cacheDir，系统可能回收，打开后可联网补齐；文字词库和历史位于持久存储。进程间文件锁防止前台和后台同时写入，临时下载原子落盘；切换领域后中止旧计划下载并清理无用文件。后台只读取学习状态，不改写历史或日历。缓存索引保存每条录音的来源和许可，录音口音取决于词典资源，非统一美式。

调度约束参考：[OpenHarmony 官方 Work Scheduler](https://github.com/openharmony/resourceschedule_work_scheduler)。

## 打包和安装

1. 从[华为官方下载中心](https://developer.huawei.com/consumer/cn/download/)安装 DevEco Studio 6，包含 HarmonyOS SDK。使用已完成实名认证的个人华为开发者账号。
2. 直接打开本目录 `english-learning-harmony`，无需再创建模板或搬文件。项目基线为 HarmonyOS 6.0.0 / API 20，适配 6.1 手机的最终结果以实际编译和真机测试为准。
3. USB 连接手机，在手机开启开发者选项、USB 调试，并确认连接授权。
4. 在 DevEco Studio 的 Project Structure → Signing Configs 中登录账号并启用自动签名，将当前手机写入调试签名。签名文件和私钥只保存在本机，勿提交到仓库。
5. 使用 IDE 的 Run 安装，或者运行：

```powershell
./scripts/Build-App.ps1 -DevEcoRoot 'C:\Program Files\Huawei\DevEco Studio'
./scripts/Install-App.ps1 -DevEcoRoot 'C:\Program Files\Huawei\DevEco Studio'
```

脚本在工具缺失、编译失败、未生成新签名包或未连接设备时会明确报错；不会自动卸载已有 App。最终产物位置：`dist/daily-english-signed.hap`。如仅检查编译，可指定 `-AllowUnsigned`，其产物不能直接安装到华为真机。当前这些脚本仅通过语法和缺失环境检查，完整构建流程仍待 DevEco 环境验证。

调试签名绑定设备且存在有效期；这与是否上架无关。到期需重新签名。新设备也需重新登记。[自动签名说明](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/ide-signing-auto)

## 词库与音频维护

`data/words.tsv` 保存原 150 词和原创双语例句，`data/extended-words.json` 保存按领域筛选的 ECDICT 850 词。许可随工程和应用资源保留。生成资源：

```powershell
npm run prepare:data
```

如需重新筛选，可运行 `python scripts/expand-dictionary.py <ecdict.csv>`，再执行上述生成命令。词库来源及校验值见 `data/SOURCES.md`。工程不再打包固定的全量 WAV，音频由手机按日期窗口下载。

## 在线数据与隐私

- [Free Dictionary API](https://dictionaryapi.dev/)：查英文释义、音标、例句。词条展示返回的来源和许可。
- [Datamuse](https://www.datamuse.com/api/)：领域相关候选词，释义来源包括 WordNet、Wiktionary。相关性属于检索建议，由用户确认加入。
- Datamuse 已公告 **2027-01-01 起要求 API Key**。本版未内置私密 Key；届时无 Key 的领域扩充可能不可用，需要更新接入方式，已下载的词库、历史、离线录音不受影响。网络服务目前曾通过本机代理取得成功响应，但手机直连可用性尚未验证。
- 音频自动联网默认开启，会向公共词典发送窗口内的单词，并向音频站点下载发音；可在设置关闭。手动查词/扩充开关独立且默认关闭。应用不会主动上传日期历史、账号或设备标识；外部站点会接收到普通网络请求信息（例如 IP）。没有广告、埋点和自建后端。
- 全部学习状态在 App 沙箱内，备份经用户选择保存位置。卸载会删除应用本地数据。

提醒机制依据：[华为代理提醒约束与 Calendar Kit 替代方案](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/agent-powered-reminder)。
